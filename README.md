# Audu Native

A simple and modern digital voice journal built using React Native, Expo and TypeScript.

## Overview

Audu Native allows users to record, play, rename, search and delete voice notes, with persistent local storage and offline functionality.

## Technology Stack

- React Native
- Expo SDK 58
- TypeScript
- Expo Router
- Expo Audio
- Expo FileSystem
- AsyncStorage
- Zod
- Lucide React Native

## Getting Started

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npx expo start
```
